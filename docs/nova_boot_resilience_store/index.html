Resilience store abstraction and optional Redis-backed implementation.

The ResilienceStore trait exposes a minimal set of operations used by the framework to implement distributed circuit breakers and rate limiters.

The optional redis-store feature provides RedisStore, a small adapter that converts Redis return values to LuaValue variants.
