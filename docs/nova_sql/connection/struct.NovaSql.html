Expand description

Main SQL integration surface.

NovaSql wraps a sea_orm::DatabaseConnection and provides helper methods to register replicas, configure caching hooks and run schema synchronization tasks. Create an instance via NovaSql::connect or connect_with_options and register it as a plugin in NovaApp.

Fields§

§db: DatabaseConnection

Primary database connection used for writes.

§allow_drop: bool

When true, schema sync may drop unused columns when reconciling models.

§tenant_resolver: Option<Arc<dyn TenantResolver>>

Optional tenant resolver used by per-tenant middleware.

pub async fn add_replica_url(&self, url: &str) -> Result<(), DbErr>

Add a replica by database URL. Returns DbErr on connection failure.

This method attempts to open a new connection to url and, on success, appends it to the replica list used by ReadWritePool for read operations.

Plugin integration for Nova applications.

Implements NovaPlugin for NovaSql so the plugin can be added to the application via NovaApp::add_plugin(...). During extend_router the plugin injects a ReadWritePool into request extensions so handlers can extract NovaDb.
